# roberts-pumpurs/tap

Homebrew casks for my apps.

```sh
brew install --cask roberts-pumpurs/tap/lull
```

| Cask | App |
|---|---|
| `lull` | [Lull](https://github.com/roberts-pumpurs/lull), a menu bar app that makes you take breaks |

The release workflow of each app updates its cask here. Do not edit a cask by hand.
